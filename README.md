# RelicFall [Dungeon] Community Page

This repository contains a GitHub Pages site for the RelicFall [Dungeon] Roblox game community. It includes:

- a homepage with game branding and a community-focused layout
- a live list of open GitHub issues
- a feedback form that opens a prefilled GitHub issue creation page
- an issue template so players can submit structured feedback

## Local preview

Open `index.html` in a browser to preview the page locally.

## GitHub Pages setup

1. Open your repository on GitHub.
2. Go to **Settings > Pages**.
3. Set the source to **Deploy from a branch**.
4. Pick the **main** branch and **/ (root)** folder.
5. Save the settings.

Your site should be published at:

https://bantais136.github.io/roblox-game-site/

## Customize it

Update the text in `index.html` and the repo name in `script.js` if needed.

## Issue workflow

The form links to the repository issue tracker so players can submit bug reports, ideas, and feedback without needing a backend.
